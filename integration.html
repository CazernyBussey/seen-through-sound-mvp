Website launcher

Open Talk to ETIB

Current WordPress.com website

An ordinary “Talk to ETIB” link or button can lead to this standalone app. Place it near the start of the page, after the main heading. This is the integration that can be used without requiring custom scripts.

The existing website has not been modified. Adding the button is a separate production change.

Modal launcher for pages that permit scripts

Test the accessible dialog launcher

The launcher opens a modal dialog, supports Escape and an explicit Close button, and returns focus to the launcher. The app requests microphone access only when Speak is selected.

<button type="button" data-etib-launcher>Talk to ETIB</button>
<script defer src="YOUR_TALK_TO_ETIB_URL/launcher.js"></script>

Replace YOUR_TALK_TO_ETIB_URL with this app’s origin. WordPress.com may remove script tags on the current hosting platform, so the ordinary link is the recommended first integration.

Accessibility validation

Keyboard navigation, dialog focus, typed requests, error states, and mobile layout can be checked automatically. iPhone Safari with VoiceOver and real microphone input still need device testing before an accessibility release claim.
